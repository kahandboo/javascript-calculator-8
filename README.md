# javascript-calculator-precourse

### 구현할 기능 목록
1. 입력 문자열에서 커스텀 구분자 정의 부분 파싱
    - 커스텀 구분자가 존재하면 구분자 배열(쉼표, 콜론)에 추가
    - 존재하지 않을 시 입력 문자열 그대로 진행
2. 에러 핸들러 - [ERROR] 메시지 출력 및 애플리케이션 종료
3. 문자열을 순회
    - 구분자 배열에 존재하는 구분자 외의 문자가 문자열에 존재하는 경우 에러 핸들러로 이동
    1. 문자 -> 숫자 변환
        - 변환된 숫자가 양수가 아닌 경우 에러 핸들러로 이동
    2. 변환된 숫자를 배열에 저장
4. 배열에 저장된 숫자들의 덧셈 계산
5. 계산 결과 출력
